## プレイ方法 (Windows)
本作は Windows 用の実行ファイル形式で公開しています。

1. [Releases ページ](ここにReleasesのURLを貼る) から最新の `FightingGame_Prototype_Windows.zip` をダウンロードしてください。
2. Zip ファイルを解凍し、中の `FightingGame.exe` を実行してください。

※ セキュリティ警告が出る場合は「詳細情報」→「実行」を選択してください。
